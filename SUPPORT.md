# Support

PDE-OBS support is public and searchable:

- Read the [project documentation](https://ru1ch3n.github.io/PartialObs--PDEBench/)
  and repository guides first.
- Use [GitHub Issues](https://github.com/ru1ch3n/PartialObs--PDEBench/issues)
  for reproducible bugs, usage obstacles, and enhancement requests.
- Follow [`CONTRIBUTING.md`](CONTRIBUTING.md) for proposed code or documentation
  changes.
- Use the private process in [`SECURITY.md`](SECURITY.md) for vulnerabilities.

Please include the PDE-OBS commit, Python and dependency versions, operating
system, the exact command, a minimal configuration, and a redacted error log.
Do not attach datasets, credentials, private cluster configuration, or model
checkpoints to public reports.
