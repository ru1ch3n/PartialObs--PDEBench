RESEARCH STUDIES / OPEN QUESTIONS

New evidence starts with a better question.

Independent studies extend the reference benchmark through new hypotheses, controlled experiments and explicit contribution plans.

All three directions are proposed. Study leads, start dates and experiments are unassigned. The intended sequence is to scope the first direction before starting a pilot; no active study or result is implied.
01
Proposed · first priority

Dynamic Observations and Forecasting

Can models maintain reliable forecasts when sensors update intermittently, asynchronously, or fail?

Beyond the reference paper

The reference study observes the initial state and predicts three stored states. This study would vary observation timing and longer-term error propagation.

Evidence that would be needed

Compare initial-only, periodic and irregular updates at the same total observation budget. Measure long-horizon error and instability; test whether timing improves performance beyond added data.

Possible contributions: Protocol design · sensor schedules · rollout analysis

Lead: Unassigned · Results: None yet

02
Proposed

Pretraining and Observation Transfer

Do pretraining gains come from more data, larger models, or more diverse observations?

Beyond the reference paper

The reference snapshot does not isolate pretraining, architecture scale and adaptation-budget effects.

Evidence that would be needed

Use matched scratch/pretrained architectures and adaptation budgets, vary target data and observation diversity, and reserve unseen combinations. Disclose data overlap as unknown until established.

Possible contributions: Checkpoint provenance · controlled adaptation · transfer analysis

Lead: Unassigned · Results: None yet

Help design this study ↗
03
Proposed

Information- and Compute-Matched Solver Evaluation

Where do classical, learned and generative methods help under the same information and resource budgets?

Beyond the reference paper

Current training histories and permissions are heterogeneous, and comparable latency and memory measurements are unavailable.

Evidence that would be needed

Match observations, physical priors and conditioning inputs. Report training and adaptation cost, inference latency, memory and error across explicit budgets.

Possible contributions: Classical baselines · permission audits · compute measurement

Lead: Unassigned · Results: None yet

FROM QUESTION TO STUDY

Evidence sets the pace.

  1. Define the new question, why the reference paper cannot answer it, and which experiment could falsify the working hypothesis.
  2. Agree on a lead, roles, permissions, controls and a minimal pilot before expanding computation.
  3. Publish a scoped technical report when evidence supports a coherent finding. A calendar date alone does not trigger a paper.
  4. Determine authorship separately for each study, with manuscript participation and accountability.
